🚀 Meu Corre

Organização financeira e gestão de ganhos para entregadores de aplicativos.

O Meu Corre é um aplicativo criado para ajudar entregadores a organizar sua rotina de trabalho, controlar seus ganhos e despesas e acompanhar seus resultados financeiros.

🎯 Objetivo

Facilitar a vida dos entregadores por meio de ferramentas simples e acessíveis de controle financeiro e organização profissional.

🛵 Público-alvo

Todos os entregadores que trabalham com aplicativos ou de forma independente.

🆓 Versão gratuita

A versão gratuita oferecerá ferramentas essenciais para que todos os entregadores possam:

- Registrar ganhos diários.
- Registrar despesas.
- Acompanhar o saldo líquido.
- Organizar os resultados financeiros.
- Definir metas de ganhos.

💰 Modelo de monetização

Modelo misto:

- Recursos básicos gratuitos para todos.
- Funcionalidades premium para usuários que desejam ferramentas avançadas.

📈 Meta do negócio

Construir um negócio sustentável, com potencial de faturamento mensal de R$ 5.000.

🛠️ Plano de desenvolvimento

Fase 1 — MVP gratuito

Desenvolvimento da primeira versão funcional:

- Registro rápido de ganhos.
- Registro de despesas essenciais.
- Controle de alimentação, combustível, recarga e manutenção.
- Cálculo automático do lucro líquido.
- Resumo financeiro diário.

Fase 2 — Organização

- Histórico diário, semanal e mensal.
- Definição de metas financeiras.
- Acompanhamento de entregas.
- Cálculo de ganhos por hora e por entrega.

Fase 3 — Recursos premium

- Relatórios financeiros avançados.
- Exportação de dados.
- Alertas de manutenção.
- Ferramentas extras para melhorar a margem de lucro.
